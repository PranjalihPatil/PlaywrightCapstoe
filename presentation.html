Design Pattern

Page Object Model

Each page class encapsulates locators and actions. Tests read like user stories.

Inheritance Chain

BasePage navigateTo(), getPageTitle()
extends ↓
HomePagenav links, login status, cart
LoginPagelogin, signup, registration form
ProductsPagesearch, add to cart, modals
CartPageitem count, remove, checkout
CheckoutPageaddress, comment, payment
ContactUsPageform fields, submit

Example: LoginPage

// Locators (constructor) this.loginEmail = page.locator( '[data-qa="login-email"]' ); this.loginButton = page.locator( '[data-qa="login-button"]' ); // Action method async login(email, password) { await this.loginEmail.fill(email); await this.loginPassword.fill(password); await this.loginButton.click(); }

Benefit: If a locator changes, update one class -- all tests using it inherit the fix automatically.

Dependency Injection

Custom Fixtures

Extends Playwright's test to auto-provide page objects and block ads.

// base.fixture.ts export const test = base.extend<PageFixtures>({ // Override page: block ads page: async ({ page }, use) => { await page.route( /google(ads|syndication)|doubleclick/, (route) => route.abort() ); await use(page); }, // Inject page objects homePage: async ({ page }, use) => { await use(new HomePage(page)); }, loginPage: async ({ page }, use) => { await use(new LoginPage(page)); }, // ... cartPage, checkoutPage, etc. });

Ad Blocking

Routes matching Google Ads, DoubleClick, and ad syndication are aborted. Prevents flaky tests from third-party scripts.

Auto-Injection

Tests declare page objects as parameters. Playwright creates and manages them automatically -- no manual setup.

Single Import

Every test file imports { test, expect } from one fixture file. Clean, consistent.

// In any test -- just declare what you need test('checkout', async ({ productsPage, cartPage, checkoutPage }) => { // All 3 page objects ready to use });

Techniques

Advanced Capabilities

N

Network Interception

Capture outgoing requests to validate the frontend sends correct queries to the backend API.

page.on('request', (req) => { if (req.url() .includes('search=')) captured = req.url(); });
M

API Mocking

Intercept API endpoints and return fake responses. Test frontend in isolation from the backend.

page.route( '**/api/productsList', (route) => route.fulfill({ body: JSON.stringify(mock) }) );
V

Visual Regression

Screenshot comparison against stored baselines. Hides dynamic elements. 5% pixel tolerance.

await expect(page) .toHaveScreenshot( 'home-page.png', { maxDiffPixelRatio: 0.05 } );
A

Accessibility

axe-core scans for WCAG violations. Filters critical issues. Threshold-based pass/fail.

D

Dialog Handling

Browser native confirm/alert dialogs handled via page.on('dialog') event listener.

B

Ad Blocking

Route-based blocking of Google Ads and DoubleClick prevents flaky tests from third-party scripts.
